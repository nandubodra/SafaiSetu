Goal

Connect the Next.js frontend to the Spring Boot API, MongoDB, JWT authentication, image storage, OTP delivery, AI classification, maps, notifications, verification, analytics, and SLA features.

Implementation order

  1. Health check and backend startup
  2. MongoDB connection
  3. OTP and JWT authentication
  4. Central frontend API client
  5. Complaint creation and listing
  6. Authority assignment and status lifecycle
  7. Worker resolution evidence
  8. Citizen verification
  9. Notifications
  10. Maps and hotspots
  11. AI and duplicate detection
  12. Analytics, SLA, testing, and deployment

Run commands

cd backend
./mvnw clean test
./mvnw spring-boot:run

cd frontend
npm install
npm run build
npm run dev

Definition of done

  • Authentication is real and protected.
  • Complaints persist in MongoDB.
  • Authority and worker workflows update the same complaint.
  • Citizens can verify a resolution.
  • Map, notifications, analytics, and SLA data come from APIs.
  • Secrets, CORS, uploads, OTP, and AI are production-safe.
